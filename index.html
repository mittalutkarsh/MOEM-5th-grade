Four pages

  • Notes: the reading page. The plan, the twelve moves as picture stories, traps, a cheat sheet and a glossary. No grading.
  • Lesson: one guided problem for each of the twelve moves, each an official MOEMS contest problem. The Concept tab is open first and teaches the move with different numbers.
  • Practice: the 23 Problems of the Week (September 2025 to February 2026), each split into steps with a worked picture story.
  • Contests: all 265 official contest problems in the file (2019–2026, Divisions E and M), grouped by the move that most likely opens each one, so he can practise one move at a time. Answers are checked against the official key, and the official method opens afterwards.

The plan

Box the question → Draw every fact → Make the move → Check every fact. The same four steps on every problem; only the move in step 3 changes.

  1. Box the question: what goes in the answer box, and in what unit?
  2. Draw every fact: one picture that holds every number in the problem.
  3. Make the move the picture shows (undo · bars · table · blocks · gaps · time block · shape · worst case · groups · cycles · digits · odd/even).
  4. Check every fact: put the answer back into each sentence. Each one gets a ✓.

How grading works

Each problem is split into steps, one number per step. He writes his method in the lined box and types the number (units, $ signs, commas and fractions like 2 1/2 are fine), then presses Check step (Enter in the answer box, Ctrl+Enter in the working box).

A wrong answer gets a nudge, and the nudges get more specific each time. After three misses he gets one final attempt; if that misses too, the step's answer is handed over and he does the next step himself. Hint for this step opens a hint without using a try (it's noted in My steps). Submit question reports how each step went and opens the verified answer and the picture story once every step is closed. Show worked answer asks twice if some steps haven't been tried.

On the Contests page each problem is one step (the final answer), checked against the official MOEMS key, and the official method opens afterwards.

Nothing is saved when the tab closes: progress and ink start fresh each visit.

P=pen on/off,Esc=pen off

The teaching pen

Press P (or the ✎ button) to write on any page. Four inks, three nibs, a highlighter, straight lines, boxes and an eraser; hold Shift for a straight stroke. Stylus only ignores your palm. On the notes page the ink stays with the text as you scroll; on the workbenches the ink stays with each problem. PNG saves the ink only, not the page underneath.
