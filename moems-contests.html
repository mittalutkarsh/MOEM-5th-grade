The plan

Box the question → Draw every fact → Make the move → Check every fact

  1. Box the question. What goes in the answer box, and in what unit?
  2. Draw every fact. A single picture with every number from the problem on it.
  3. Make the move. Which move does the picture show?
  4. Check every fact. Put the answer back into each sentence.

The moves

  • Undo it (work backwards)
  • Bars and units (bar model)
  • Table of cases (organized list)
  • One block (find the repeating group)
  • Gaps and posts (count the spaces)
  • Same time block (rates over one shared time)
  • Draw the shape (measure the picture)
  • Worst case (the unluckiest draws)
  • Friendly groups (regroup before calculating)
  • Cycles and remainders (find the repeating block)
  • Digit detective (place value, carries, divisibility)
  • Odd and even (parity rules out answers)

Not sure which move? Draw the picture first; it usually tells you. Still stuck? Try the same problem with tiny numbers.
